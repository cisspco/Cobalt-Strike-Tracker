### KnowledgeDeliver ViewState 역직렬화 취약점(CVE-2026-5426) — BLUEBEAM 웹셸 경유 Cobalt Strike BEACON 배포 (신규 검증)
- 대상: KnowledgeDeliver(일본 Digital Knowledge사 LMS) 고객사 중 2026-02-24 이전 배포판 사용 조직
- 초기 침투: 모든 고객 배포판에 동일하게 하드코딩된 사전공유 `machineKey`를 악용해 `__VIEWSTATE` 파라미터 조작 → ASP.NET ViewState 역직렬화
- Cobalt Strike 역할: BLUEBEAM(.NET 인메모리 웹셸, Godzilla 계열)이 `w3wp.exe`에 상주하며 1단계 거점 확보 → 이후 가짜 "보안 인증 플러그인" 설치파일을 통해 최종 페이로드로 Cobalt Strike BEACON을 최종 사용자 워크스테이션에 설치. BEACON 페이로드는 조직명을 키로 암호화됨
- 관측 시점: 2025년 하반기(Mandiant 사고대응 기준), 보고서 게재 2026-05-25
- 특이사항: C2 도메인/IP, 맬리어블 프로파일, 워터마크는 보고서에 구체적으로 공개되지 않음(비식별 처리) — 따라서 신규 차단 대상 없음. BLUEBEAM 자체 SHA-256 해시만 공개됨(로더 역할로 `sha256.txt`에 등재)
- 출처: Mandiant/Google Cloud Blog, "Exploitation of KnowledgeDeliver via ViewState Deserialization Vulnerability" (2026-05-25) — fetched, verified

### APT24 — Cobalt Strike Beacon을 BADAUDIO 다운로더의 2단계 페이로드로 사용
- 대상: 다중 벡터 공격으로 전환 중인 APT24 캠페인 (Mandiant 보고서 기준 산업/국가 세부사항 제한적)
- 초기 침투: BADAUDIO 1단계 다운로더가 하드코딩된 AES 키로 페이로드 복호화 후 메모리 내 실행
- Cobalt Strike 역할: BADAUDIO → (일부 사례에서) Cobalt Strike Beacon 2단계 페이로드로 메모리 내 실행. 모든 BADAUDIO 사례에 Cobalt Strike가 확인된 것은 아님(보고서 명시)
- 관측 시점: 보고서 게재 2025-11-20
- 특이사항: Beacon 페이로드에 이전 별도 APT24 캠페인에서도 관측된 동일 워터마크 해시(`BeudtKgqnlm0Ruvf+VYxuw==`) 포함
- 출처: Mandiant/Google Cloud Blog, "APT24's Pivot to Multi-Vector Attacks" (2025-11-20) — fetched, verified

### GOOTLOADER — Cobalt Strike BEACON을 2차 페이로드(FONELAUNCH 경유)로 배포 (구 캠페인)
- 대상: GOOTLOADER 감염 체인 전반 (산업/국가 특정 불가, Mandiant 장기 추적 대상)
- 초기 침투: GOOTLOADER 다운로드/실행 → 레지스트리 페이로드 2개 저장(FONELAUNCH + Cobalt Strike BEACON 또는 SNOWCONE)
- Cobalt Strike 역할: FONELAUNCH(.NET 로더)가 두 번째 레지스트리 페이로드를 디코딩/메모리 내 실행 → Cobalt Strike BEACON(또는 대체로 SNOWCONE)이 최종 백도어로 동작
- 관측 시점: 보고서 게재 2023-01-26 (오래된 인프라 데이터 — IP 재할당 가능성에 유의)
- 출처: Mandiant/Google Cloud Blog, "Welcome to Goot Camp" (2023-01-26) — fetched, verified
